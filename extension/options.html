Job Apply Kit settings

Everything here is stored in this browser. Changes save as you type.

Google Sheet link

Both live in your job-search spreadsheet: applications go to your tracker tab, and referrals go to a tab named “Referral Apps”. If that tab isn't there yet, it's added the first time the link is tested. Setting this up takes about two minutes, once.

Open your job-search spreadsheet and copy the address from the browser bar. It's written into the script when you copy it in step 1.
  1. (a small script that runs inside your own Google account).
  2. Open a new Apps Script project (script.new). It's separate from any script already attached to your sheet, which is left alone.
  3. Delete the few lines in the editor, paste, and click the save icon.
  4. Click Deploy → New deployment. Click the gear and pick Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  5. Click Authorize access and pick your account. Google warns that the app isn't verified, because it's your own script: choose Advanced → Go to … (unsafe) → Allow.
  6. Copy the Web app URL it shows and paste it below.
Treat this link like a password: anyone who has it can read and add rows in these two tabs.

Resume link

Added to every full referral message as “Resume: link”. Upload your resume to Google Drive, set sharing to “Anyone with the link”, and paste the link.

About you

Used by Fill this page on job applications. Anything left blank is skipped, so the form's field stays empty for you to answer.

When you log an application

Extra columns your tracker has. Each is only written if the tracker has a column for it.

If the status column is a dropdown, the option that matches is picked for you. Leave either box blank to fill that column in yourself. The login can be changed per application in the popup; passwords are best kept out of a spreadsheet.

Answers to questions you keep getting

When an application question contains any of your words, Fill this page enters your answer. Separate several words with commas. Yes/No answers tick the matching choice.

Referral message wording

The message is built from these. Words in braces are filled in for you.

{name} {me} {full_name} {headline} {pitch} {position} {company} {resume_line} {job_line}

LinkedIn profiles

It reads only the profile you have open, only when you open the popup, and changes or sends nothing. LinkedIn's terms are written broadly against extensions that copy profile details, so turn this off if you'd rather not; the name is then taken from the tab title and you type the company.
